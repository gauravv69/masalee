# Masalee 🌶️

Masalee is a modern ecommerce frontend for an Indian spices brand, built with a focus on performance, scalability, and clean UI/UX.

## Tech Stack

- React
- TypeScript
- Vite
- TailwindCSS
- React Router
- Vercel (deployment)

## Features

- Modern, responsive ecommerce homepage
- Reusable component architecture
- Scalable folder structure
- Fast performance with Vite
- Ready for backend integration (products, cart, payments)

## Project Structure

src/
components/ – reusable UI and layout components  
pages/ – route pages  
features/ – domain logic  
styles/ – global styles
